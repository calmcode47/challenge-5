# Occasio — Celebration & Event Planner

Occasio is an AI-powered celebration and event planning assistant built for Google PromptWars Challenge 5. Designed on the architectural principle of a deterministic computational core paired with contextual AI enrichment, Occasio enables individuals and communities to seamlessly organize weddings, birthdays, and community festivals with mathematically verified budgets, lead-time adaptive timelines, actionable vendor checklists, and personalized event concepts.
